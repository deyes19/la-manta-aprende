# La Manta Aprende para Android

Versión 0.3.0, distribución del 28 de octubre de 2026.

Descargar el APK, abrirlo en Android e instalarlo una vez. Las lecciones, imágenes y audios están incluidos. Android 8 o posterior y Android System WebView actualizado. La firma y el flujo de los archivos empaquetados se verificaron; la instalación en un dispositivo Android real debe probarse antes de distribuir a todas las familias.

El ZIP contiene el mismo APK, instrucciones y huella SHA-256. No contiene datos estudiantiles ni claves de firma. El código fuente está en la rama main del repositorio.
