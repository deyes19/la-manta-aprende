# La Manta Aprende para las familias — Android

El archivo **La_Manta_Aprende_Android_Sin_Internet.apk** incluye las 19 rutas del cuarto período de Matemáticas, Lengua Castellana y Ciencias Sociales, desde transición hasta quinto. Las imágenes, lecciones y audios están dentro del archivo. No necesita cuenta ni Internet para aprender.

## Instalar una vez

1. Descargar el APK en el celular. También se puede recibir por cable, memoria o transferencia local desde otro equipo.
2. Abrir el archivo y tocar **Instalar**. Si Android pide autorización para instalar desde la aplicación que abrió el archivo, permitir esa instalación.
3. Abrir el icono **La Manta Aprende**.
4. Escribir un alias, elegir grado, crear el perfil y abrir la asignatura y unidad.

Requisitos: Android 8.0 o posterior, Android System WebView actualizado y aproximadamente 250 MB libres para instalar y guardar avances. La descarga ocupa aproximadamente 72 MB.

## Usar sin conexión

Se puede activar el modo avión antes de la primera apertura. La aplicación comienza con los audios guardados. En **Elegir voz** se puede probar una voz del dispositivo si está disponible; el audio incluido permanece como respaldo.

El niño puede escuchar, repetir, escribir en el cuaderno y usar las actividades. Los pasos confirmados se guardan en ese celular. Para varios niños, crear un perfil por alias. Al volver, seleccionar el alias y tocar **Reanudar**. Las respuestas que todavía no se hayan confirmado no cuentan como un paso terminado.

Para cerrar, usar el botón Atrás de Android y confirmar **Salir**. No borrar los datos de la aplicación ni desinstalarla si se necesitan conservar avances.

## Mostrar el trabajo al docente

Mostrar el cuaderno y la actividad. En **Docente → Exportar JSON o CSV**, elegir dónde guardar el archivo en el celular. Después se puede entregar ese archivo al docente. El reporte no se envía automáticamente y los datos de la versión web no se trasladan solos a esta aplicación.

## Si no abre

Comprobar la versión de Android y que Android System WebView esté actualizado. En algunos celulares se necesita acceso a Internet para actualizar ese componente del sistema una vez; después las lecciones funcionan sin red.

Esta primera distribución está firmada para instalación directa. Se verificaron su firma, los recursos completos y el flujo de los archivos empaquetados sin red en Chromium. La instalación y el comportamiento en un celular Android real quedan pendientes de comprobación. Probar primero en un celular antes de repartirla a todas las familias.
