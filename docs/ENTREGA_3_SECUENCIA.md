# Entrega 3: secuencia por temas y apoyos visuales

La estructura anterior explicaba todos los temas, concentraba sus copias y ejercicios en un bloque y terminaba con todas las prácticas. Ahora cada tema se explica, se escribe en tarjetas separadas y se practica antes de iniciar el siguiente. Cada ejercicio escrito se revisa inmediatamente. Se conservan las misiones y comprobaciones finales y las referencias a las mallas originales.

19 rutas ejecutables, 665 pantallas, 75 temas de primaria; transición mantiene sus tres experiencias integradas. No se crean unidades vacías ni nuevos contenidos institucionales. Se dividen ejercicios que mezclaban letras, formas y diagramas, tradiciones y municipio, o sujeto/predicado y secuencias. El guion de autoría contiene relaciones explícitas entre ejercicio y tema; la regeneración es idempotente.

El motor muestra el tema actual y el cierre de su práctica. Los ejemplos tienen modelos SVG locales de dibujo o diagramas existentes. La multiplicación del piloto permite construir grupos de objetos y quitar elementos de más. Fracciones de tercero combina partes coloreables, reparto en grupos iguales y representación de multiplicaciones; la comprobación valida las partes y el reparto, no solo un total digitado.

## Actualización de avances

Primaria usa versión 2. Las migraciones incluyen el orden anterior, conservan IDs, intentos, ayudas, productos, observaciones y autoevaluación. Reanudan el primer paso pendiente y mantienen los recorridos terminados. Los pasos derivados de una copia anterior se conservan como confirmaciones del estudiante, no como evidencia verificada del cuaderno. Un avance incompatible se conserva sin sobrescribirlo. Los ejercicios que cambian de presentación mantienen las respuestas históricas como evidencia anterior; la observación docente sigue siendo necesaria para atribuir comprensión de una representación nueva.
